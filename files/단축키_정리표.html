프리미어 프로 주요 단축키 정리표

분류 단축키 기능 설명
영상 컷 편집V클립 선택 도구클립을 선택하고 이동하거나 간단하게 트리밍합니다.
영상 컷 편집Ctrl + K인디케이터 위치에서 자르기재생 헤드 위치에서 클립을 바로 분할합니다.
영상 컷 편집C자르기 도구선택한 클립을 인디케이터 위치에서 분할합니다.
영상 컷 편집Q / W이전·이후 잔물결 컷인디케이터 기준 앞(Q) 또는 뒤(W) 부분을 자르고 당겨옵니다.
영상 컷 편집Shift + Delete잔물결 삭제빈 공간을 남기지 않고 선택한 클립을 삭제합니다.
영상 컷 편집Delete / Backspace클립 삭제선택한 영상이나 오디오 클립을 삭제합니다.
영상 컷 편집Ctrl + D기본 전환 적용선택한 클립 경계에 기본 전환 효과를 적용합니다.
영상 컷 편집T문자 도구프로그램 모니터를 클릭해 화면 자막을 생성합니다.
재생·정지Space / L재생·2배속 재생스페이스바로 재생하고 L키로 2배속 재생합니다.
재생·정지J역재생J키를 눌러 역방향으로 재생합니다. 반복 입력 시 속도가 빨라집니다.
재생·정지K / Space정지K키 또는 스페이스바로 재생을 멈춥니다.
타임라인 보기← / → / ↑ / ↓프레임·클립 이동좌우 화살표로 앞뒤로 이동하고 위아래 화살표로 클립을 이동합니다.
타임라인 보기+ / -타임라인 확대·축소타임라인을 확대하거나 축소합니다.
타임라인 보기Alt + 휠타임라인 가로 스크롤Alt를 누른 상태에서 마우스 휠로 타임라인을 이동합니다.
타임라인 보기W클립 전체 보기타임라인 패널에 클립이 모두 보이도록 맞춥니다.
클립 복사Alt + 드래그클립 복사Alt를 누른 상태에서 클립을 드래그해 복사합니다.
프로젝트 관리Ctrl + S프로젝트 저장작업 결과를 프로젝트 파일에 저장합니다.
프로젝트 관리Ctrl + M내보내기완성 영상을 비디오 파일로 인코딩해 출력합니다.
